# Tejas Nikam — AI/ML Engineer Portfolio

Personal portfolio site built with React, Vite, Tailwind CSS and Framer Motion.

**Live site:** https://tejas-nikam-portfolio.vercel.app

## Sections

- **Hero** — animated intro with typewriter tagline and key stats
- **About** — bio, availability status, and an animated tech marquee
- **Skills** — languages, ML/DL, GenAI/LLMs, databases, data tools and backend/DevOps
- **Projects** — Multi-Source RAG System, CLICKK (IEEE-published AI coding assistant), Deepfake Detection Model, Chest X-Ray Multi-Label Classification, and NeuralWatch
- **Experience** — ML Engineer Intern (Enpointe), Data Science Intern (Qspiders), IBM SkillsBuild
- **Education & Certifications**
- **Achievements** — IEEE publication, CSI IT Council, hackathon finish
- **Contact** — direct links plus a message form

## Tech stack

- [React 19](https://react.dev) + [Vite](https://vite.dev)
- [Tailwind CSS v4](https://tailwindcss.com)
- [Framer Motion](https://www.framer.com/motion/) for animations (parallax, magnetic buttons, 3D tilt cards)
- [react-icons](https://react-icons.github.io/react-icons/)

## Development

```bash
npm install
npm run dev      # start dev server
npm run build    # production build to dist/
npm run preview  # preview the production build locally
```

## Deployment

Deployed on [Vercel](https://vercel.com), connected to this GitHub repo for automatic deploys on every push to `main`. Framework settings are pinned explicitly in `vercel.json`.
